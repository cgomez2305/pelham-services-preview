# Pelham 1.9.5 / plugin 1.8.6

Recovered from the user-supplied theme 1.9.4 and plugin 1.8.5 archives.

UIArc-inspired radio-card selection replaces the quote dropdown only when JavaScript is available. Native radio keyboard behavior, descriptions editable through UI Quote Choice settings, selected border and radio indicator, preserved backend service value, URL preselection and recovered drafts. No React/Motion dependency, Pro source or UIArc code copied. FAQ uses native details and progressive CSS height transitions, with reduced-motion and existing pause control respected.

Browser tests: three widths (1440, 390, 320), four choices, preselection, keyboard arrows, dependent instructions, retained message, no overflow and no-JS dropdown. Screenshots in audit/uiarc. No real submissions or SMTP test.

Install both ZIPs, replacing the previous packages, and clear cache. No content reimport required. Live hosting was not modified. Local database retains older page content: root static HTML was intentionally not overwritten using that older database.

References: https://uiarc.dev/components/radio-cards, https://uiarc.dev/components/accordion, https://uiarc.dev/docs/motion. Native adaptation, not a direct UIArc installation.
